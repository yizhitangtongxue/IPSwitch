# IP Switch 工具

## 概述

IP Switch 是一个 Windows 应用程序，允许用户通过简单的界面快速切换网络配置。该工具支持设置静态 IP 地址和 DNS 服务器，适用于需要频繁更改网络配置的场景。

## 特性

- **静态 IP 和 DNS 设置**：手动输入并应用静态 IP 地址、子网掩码、默认网关和 DNS 服务器。
- **多配置管理**：支持加载多个网络配置文件，并在不同配置之间轻松切换。
- **日志记录**：详细记录所有操作，便于排查问题。

## 安装步骤

1. **下载源代码或可执行文件**：
   - 从 GitHub 或其他发布平台下载项目源代码或预编译的可执行文件。

2. **运行应用程序**：
   - 如果你下载的是源代码，请确保你已经安装了 Visual Studio 并打开项目进行编译。
   - 如果你下载的是可执行文件，请以管理员权限运行 `.exe` 文件。

3. **配置文件准备**：
   - 创建一个名为 `ipconfig.json` 的 JSON 配置文件，并将其放置在应用程序目录中。
   - 配置文件格式详见“配置文件格式”部分。

## 使用方法

1. **启动应用程序**：
   - 以管理员权限运行 `IPSwitch.exe`。

2. **选择配置**：
   - 在下拉菜单中选择你要应用的网络配置。

3. **应用配置**：
   - 点击“应用配置”按钮，系统将自动设置相应的 IP 地址和 DNS 服务器。

4. **查看日志**：
   - 打开 `ipswitch.log` 文件，查看详细的操作日志。

## 配置文件格式

配置文件 `ipconfig.json` 必须是有效的 JSON 格式，并且包含以下字段：

```json
[
    {
        "Name": "家用网络",
        "ConnectionName": "以太网",
        "IpAddress": "192.168.1.100",
        "SubnetMask": "255.255.255.0",
        "Gateway": "192.168.1.1",
        "Dns1": "8.8.8.8",
        "Dns2": "1.1.1.1"
    },
    {
        "Name": "工作网络",
        "ConnectionName": "以太网",
        "IpAddress": "192.168.2.100",
        "SubnetMask": "255.255.255.0",
        "Gateway": "192.168.2.1",
        "Dns1": "8.8.8.8",
        "Dns2": "1.1.1.1"
    }
]
